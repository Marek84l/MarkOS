# MarekOS

MarekOS is a Debian Testing-based Linux distribution focused on a polished,
easy-to-use desktop experience.

## Desktop environments

- GNOME - primary desktop
- Cinnamon
- i3

## Status

Early development.

## First milestone

MarekOS 0.1:
- Debian Testing base
- GNOME desktop
- Bootable Live ISO
- Installable system
